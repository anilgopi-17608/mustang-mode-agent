## 🤖 What This Does

Three autonomous AI agents running 24/7 in the cloud:

### 🏎️ Job Agent (4× daily)
- Scans Gmail for engineering jobs
- AI-powered job scoring (Gemini 1.5)
- Beautiful HTML email digests
- Cover letter openers generated by AI

### 🌅 News Agent (Daily 7 AM IST)
- Fetches news from 10+ RSS sources
- Categories: AI, Tech, Medical Devices, India Tech, Engineering
- AI-summarized in plain English

### 📈 Market Updater (Every Hour)
- 🇮🇳 Indian markets (Nifty, Sensex, top stocks)
- 🇺🇸 US markets (S&P, NASDAQ, Apple, Tesla, etc.)
- ₿ Crypto (BTC, ETH, SOL, ADA)
- 💵 Forex + Gold

## 🛠️ Tech Stack

- **Language:** Python 3.11
- **AI:** Google Gemini 1.5 Flash
- **Email:** Gmail API + SMTP (OAuth 2.0)
- **Finance:** Yahoo Finance API
- **Cloud:** GitHub Actions (cron scheduled)
- **Frontend:** HTML/CSS/JavaScript
- **Hosting:** GitHub Pages
